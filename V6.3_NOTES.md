# V6.4 — General ROS Recognition

Main fixes:
- Removes the old Pd alpha-arylation route as a default/fallback interpretation.
- Every uploaded ROS is analyzed independently.
- Previous Streamlit structure-recognition state is cleared when file content changes.
- Reaction assignment now combines current-upload AI interpretation, validated molecular-graph bond changes, and current-upload reagent signatures.
- If evidence is insufficient, the app says `Requires structure verification` rather than reusing an earlier mechanism.
- Mechanism cards are generated from the reaction class instead of a fixed alpha-arylation sequence.
- Retains V6.2.2 dual structure renderer: RDKit rdMolDraw2D PNG with Pure-Pillow molecular-graph fallback.
- Exact SMILES/stereochemistry are withheld when graphical recognition is uncertain.
