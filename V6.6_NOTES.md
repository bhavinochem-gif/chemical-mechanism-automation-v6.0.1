# V6.6 Notes

## New modules

- `modules/drawing_workspace.py`
  - Ketcher/Streamlit drawing adapter
  - streamlit-chem primary
  - streamlit-ketcher fallback
  - direct SMILES recovery field

- `modules/direct_graph_engine.py`
  - SMILES/Molfile/RDKit Mol → sanitized molecular graph
  - atom/bond JSON
  - canonical isomeric SMILES
  - molecular formula / MW

- `modules/reaction_step_model.py`
  - structured reaction-step model
  - reactants/products/conditions
  - reaction SMILES

- `modules/route_builder.py`
  - sequential multi-step synthesis route state
  - route validation

- `modules/direct_reaction_analyzer.py`
  - connects direct graphs to V6.3/V6.4 engines
  - reaction-center detection
  - reaction classification
  - mechanism generation
  - graphical intermediates

- `modules/reaction_input_adapter.py`
  - Reaction SMILES parser
  - MDL RXN parser

- `modules/reaction_export.py`
  - RXN export

## Retained from V6.5

- Advanced OCSR
- graphical mechanism pathway
- curved-arrow rendering framework
- reaction-center highlighting
- chemistry JSON knowledge base
- AI provider router
- PDF/image workflow as an optional legacy page

## Why V6.6 is more reliable

V6.5:
image → OCSR candidate → validation → graph

V6.6:
drawing/direct format → graph → validation

This removes the most error-prone optical recognition stage when the chemist can
provide the structure directly.
