# V6.5 — Advanced OCSR + Structure Verification Engine

V6.5 retains V6.3 general ROS recognition and the V6.4 graphical mechanism engine, but changes the image-to-graph stage substantially.

## New structure-recognition pipeline

1. Detect individual molecular drawings on the full reaction scheme.
2. Crop each molecule separately from reagent/condition text and reaction arrows.
3. Generate multiple high-resolution OCSR image variants.
4. Ask the vision model for multiple structure candidates instead of one forced SMILES.
5. Validate every candidate with RDKit.
6. Attempt a conservative vision repair only for invalid candidates.
7. Render every valid molecular graph back to a 2D structure.
8. Compare the rendered candidate against the original crop with an independent visual-verification pass.
9. Auto-accept only high-scoring candidates; otherwise require user confirmation.
10. Compare selected reactant and product candidates by maximum common substructure before reaction-center analysis.

## Important limitation

RDKit validates chemical graph syntax/valence; it does not prove that OCSR read the drawing correctly. V6.5 therefore separates `RDKit valid` from `image verified` and never treats low-confidence candidates as exact structures automatically.

## Deployment

Python 3.12 remains recommended for Streamlit Cloud. V6.5 keeps the V6.2.2/V6.4 structure-rendering fallback so lack of `rdMolDraw2D` does not crash the whole app.
